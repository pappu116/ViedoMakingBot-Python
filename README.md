# YTFB Studio — ভিডিও + অটো আপলোড (১০০% ফ্রি)

একটি Windows ডেস্কটপ অ্যাপ, যেটা এক জায়গা থেকে পুরো কাজটা করে:

**আইডিয়া/স্ক্রিপ্ট → ভয়েস → ছবি/ভিজ্যুয়াল → ভিডিও রেন্ডার → YouTube ও Facebook-এ অটো আপলোড**

কোনো paid API লাগে না। কোনো API key ছাড়াই কাজ করে।

## দ্রুত শুরু (৩ ধাপ)

```bat
pip install -r requirements.txt
python gui.py
```

১. **টুলস** পেজে গিয়ে → “বাংলা ফন্ট নামান” আর “ব্রাউজার ইনস্টল” চাপুন (একবারই লাগে)।
২. **ভিডিও তৈরি করুন** → আইডিয়া লিখুন বা **নিজের স্ক্রিপ্ট** দিন → ৭ ধাপ শেষ করুন।
৩. **একাউন্ট** পেজে লগইন করুন → **পাবলিশ** পেজ থেকে YouTube/Facebook-এ দিন।

> লগইন করতে ব্রাউজার খুলবে — সেখানে নিজের একাউন্টে লগইন করুন, অ্যাপ নিজেই ধরে ফেলবে এবং সেশন সেভ করবে। পরে আর লগইন লাগবে না।

### ভিডিওর মান যেভাবে ঠিক করা হয়েছে

- **ভাষা:** **স্ক্রিপ্টের লেখাই ভাষা ঠিক করে**। বাংলা স্ক্রিপ্ট দিলে বাংলা কণ্ঠই ব্যবহার হবে — ড্রপডাউন ভুল থাকলেও। ভয়েস পেজও নিজে থেকে সেই ভাষায় চলে যায়। (আগে ড্রপডাউন বাংলা স্ক্রিপ্টকে ইংরেজি বানিয়ে দিত।)
- **স্টাইল:** ১২টি — সিনেমাটিক, ড্রামাটিক, শিক্ষামূলক, **টিউটোরিয়াল**, উজ্জ্বল, অ্যানিমে, কার্টুন, **হোয়াইটবোর্ড**, **স্কেচ**, রিয়ালিস্টিক, স্লাইড, পাপেট। অ্যানিমেশন স্টাইলগুলো (anime/cartoon/whiteboard/sketch/puppet/slide) স্বয়ংক্রিয়ভাবে **শুধু AI আর্ট** ব্যবহার করে — কখনো আসল ফটো/ফুটেজ ঢোকে না।
- **মুভমেন্ট:** Zoom-In, Zoom-Out, Ken Burns (জুম+প্যান), Pan, স্থির — ছবি ও ভিডিও ক্লিপ দুটোতেই কাজ করে (ধাপ ২-এ বাছুন)।
- **সাবটাইটেল:** বড় headline-সাইজ ফন্ট (ফ্রেমের ~৭%), সত্যিকারের **কালো আউটলাইন/স্ট্রোক** — উজ্জ্বল বা ব্যস্ত ফুটেজেও স্পষ্ট পড়া যায়। কারাওকে স্টাইলে বলার সময় শব্দটা হলুদ হয়ে জ্বলে ওঠে। ক্যাপশন কখনো বাক্যের মাঝখানে ভাগ হয় না।
- **রিয়ালিস্টিক:** Wikimedia Commons থেকে **আসল ভিডিও ক্লিপ (B-roll)** ব্যবহার হয় — স্থির ছবির স্লাইড-শো নয়। ক্লিপ না পেলে ছবি, তারপর গ্রেডিয়েন্ট।
- **টপিক অনুযায়ী ছবি:** প্রতিটি দৃশ্যের লেখা থেকে ইংরেজি ভিজ্যুয়াল কীওয়ার্ড বের করা হয় (**৪০০+ শব্দের বাংলা অভিধান**)। কোনো দৃশ্যের শব্দ না মিললে ধাপ ৫-এ ⚠ সতর্কতা দেখায় — তখন **"AI দিয়ে দৃশ্য মিলান"** চেপে AI দিয়ে প্রতিটি দৃশ্যের নিখুঁত ইংরেজি প্রম্পট বানিয়ে নিন, অথবা নিজে কীওয়ার্ড লিখুন। দুর্বল দৃশ্যে স্টক ভিডিও আর ব্যবহার হয় না।
- **ভয়েস:** edge-tts ভয়েসে high-pass + কম্প্রেশন + **−১৫ dB RMS loudness normalization** — সোশ্যালের জন্য জোরালো ও সমান শোনায় (আগে প্রায় ৭ dB চাপা ছিল)।

## ১০০% ফ্রি, key ছাড়াই যা ব্যবহার হয়

| কাজ | যেভাবে |
|---|---|
| ভয়েস | **edge-tts** (ফ্রি, key ছাড়া, বাংলা পুরুষ/মহিলা কণ্ঠ) → ব্যর্থ হলে gTTS → অফলাইনে Windows কণ্ঠ |
| ছবি | **Pollinations AI** (key ছাড়া) → **Wikimedia Commons** → **Picsum** → না পেলে সুন্দর গ্রেডিয়েন্ট |
| ভিডিও ক্লিপ | **Wikimedia Commons** (ফ্রি লাইসেন্স, key ছাড়া) — টপিক অনুযায়ী আসল ফুটেজ |
| মিউজিক | অ্যাপ নিজেই তৈরি করে দেয় — সম্পূর্ণ নিজের সুর, তাই কপিরাইট ঝামেলা নেই |
| স্ক্রিপ্ট | ডিফল্ট টেমপ্লেট (অফলাইন, বাংলা সহ) · চাইলে ফ্রি key দিয়ে Gemini / Groq / OpenRouter / Ollama |

**AI key দিলে আরও ভালো স্ক্রিপ্ট:** সেটিংস → AI → প্রোভাইডার বেছে key বসান।
**ছবির লিমিট বাড়াতে:** Pollinations-এর ফ্রি সীমা প্রতি ৪৫ সেকেন্ডে ১টি ছবি। সেটিংস → “Pollinations টোকেন” দিলে সীমা উঠে যায় (ঐচ্ছিক)।

## CLI দিয়েও চলে

```bat
python main.py                                  :: ইন্টারঅ্যাকটিভ মেনু
python main.py generate --topic "বাংলাদেশের নদী" --lang bn --style cinematic
python main.py generate --script my_script.txt --images-dir "D:\my photos"
python main.py login --platform youtube --profile acc1
python main.py run --count 3 --platforms youtube,facebook --profiles acc1
python main.py upload --video output\videos\x.mp4 --dry-run
python main.py voices
python main.py selftest
```

## সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| **ভিডিও ইংরেজিতে হয়ে যাচ্ছে** | এখন স্ক্রিপ্টের লেখাই ভাষা ঠিক করে — বাংলা লিখলে বাংলা কণ্ঠ। ধাপ ৩-এর "নির্বাচিত কণ্ঠ" কার্ডে ভাষা দেখে নিন |
| **ছবি স্ক্রিপ্টের সাথে মিলছে না** | ধাপ ৫-এ ⚠ চিহ্ন দেখলে ওই দৃশ্যের কীওয়ার্ড লিখুন, অথবা **"AI দিয়ে দৃশ্য মিলান"** চাপুন |
| ভিডিওতে বাংলা ভাঙা দেখাচ্ছে | Tools → “বাংলা ফন্ট নামান” চাপুন (নাহলেও Nirmala UI দিয়ে ঠিক দেখাবে) |
| সাবটাইটেল ছোট/অস্পষ্ট লাগছে | ধাপ ৪-এ ক্যাপশন স্টাইল বদলান — “বোল্ড আউটলাইন” সবচেয়ে স্পষ্ট |
| ছবি টপিকের সাথে মিলছে না | ধাপ ৫-এ সেই দৃশ্যের **কীওয়ার্ড** বদলে দিন (ইংরেজিতে ভালো) → “নতুন ছবি” |
| রেন্ডার ধীর / ইন্টারনেট ধীর | স্টক ভিডিও বন্ধ করুন (ধাপ ২), অথবা থাকা ক্যাশ ব্যবহার হবে — দ্বিতীয়বার দ্রুত হয় |
| ভয়েস তৈরি হচ্ছে না | ইন্টারনেট দেখুন, অথবা Tools → “ভয়েস টেস্ট” চালান। অফলাইনে Windows-এ বাংলা ভয়েস না থাকলে ইংরেজি বা অনলাইন মোড লাগবে |
| AI ছবি আসছে না | ফ্রি লিমিট (৪৫ সে/ছবি)। বাকি দৃশ্যে স্টক ছবি/ক্লিপ/গ্রেডিয়েন্ট ব্যবহার হবে — অথবা সেটিংসে টোকেন দিন |
| আপলোডে “বাটন পাওয়া যায়নি” | সাইটের UI বদলে গেছে → `core\upload\selectors.py`-তে সিলেক্টর আপডেট করুন, আর আগে **ড্রাই-রান** দিয়ে পরীক্ষা করুন |
| ব্রাউজার খুলছে না | Tools → “ব্রাউজার ইনস্টল”, তারপর “ব্রাউজার যাচাই” |

## ⚠️ দায়িত্ব ও নিরাপত্তা

- YouTube/Facebook-এর **নিয়ম (ToS) মানা আপনার দায়িত্ব**। অটোমেশন ব্যবহারে একাউন্টে সীমাবদ্ধতা আসতে পারে।
- ডিফল্টে ডিলে (৩০–৯০ সে) আর দিনে সর্বোচ্চ আপলোড লিমিট রাখা আছে — **এগুলো কমানো উচিত নয়**, নিজের একাউন্ট বাঁচানোর জন্যই।
- কনটেন্ট আপনার নিজের হতে হবে। কারও কপিরাইট করা ভিডিও/মিউজিক আপলোড করবেন না।
- অ্যাপের ভেতরের মিউজিক নিজে তৈরি করা, তাই কপিরাইট-মুক্ত।
